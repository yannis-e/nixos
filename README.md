> [!CAUTION]

Hosts:
- glade ~ My laptop; an HP Victus 15 with an AMD Ryzen 7 7000-series CPU, an NVIDIA RTX 4050 Laptop GPU, 16 GiB of RAM, and an NVMe SSD.
